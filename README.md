# Arena FPS — мультиплеерный шутер на Godot 4

## Онлайн-версия (как сайт)
Игра открывается в браузере по ссылке. Сервер работает на Render в Docker-контейнере:
nginx отдаёт веб-версию из `server/web`, а `/ws` пересылает на Godot-сервер (WebSocket).

**Деплой на Render:** New → Web Service → выбрать репозиторий → Runtime: Docker → Free → Create.
Через несколько минут игра будет по адресу `https://<имя>.onrender.com`.

**После правок кода** веб-версию нужно пересобрать: в Godot «Проект → Экспорт → Web → Экспорт проекта»
в `server/web/index.html` (шаблоны экспорта ставятся через «Редактор → Управление шаблонами экспорта»),
затем залить изменения на GitHub — Render пересоберёт сам.

Бесплатный Render засыпает через 15 минут без игроков — первое открытие сайта будит его ~1 минуту.

## Запуск
1. Скачай Godot **4.4** или новее (обычная версия, не .NET): https://godotengine.org/download
2. Распакуй архив, в Godot нажми **Импорт** → выбери `project.godot`.
3. **F5** — запуск. Откроется меню.

## Как играть с друзьями
- **Ты хост:** «Создать игру». Друзья вводят твой IP и жмут «Подключиться».
- **В одной Wi‑Fi:** IP вида `192.168.x.x` (смотри `ipconfig` в cmd).
- **Из игры на ПК к онлайн-серверу:** в поле адреса введи `имя.onrender.com`.
- **Через интернет со своего ПК:** либо проброс порта **7777 TCP** на роутере, либо Radmin VPN / ZeroTier (тогда даёшь IP из этой программы), либо выделенный сервер на VPS.
- Проверить у себя: запусти игру два раза (в Godot: Отладка → Запустить несколько экземпляров → 2), в одном «Создать игру», в другом «Подключиться» к `127.0.0.1`.

## Выделенный сервер (без окна, например на VPS)
```
godot --headless --path . -- --server
```
Сервер считает попадания, урон, смерти и счёт — клиент не может «нарисовать» себе убийство.

## Управление
WASD — ходьба, Shift — бег, Пробел — прыжок, ЛКМ — огонь, ПКМ — прицел (коллиматор), R — перезарядка, Tab — таблица счёта, Esc — пауза/курсор.

## Параметры запуска (для тестов)
- `-- --bot` — игрок управляется ботом (бегает и стреляет сам)
- `-- --join=IP --name=Ник` — сразу подключиться
- `-- --host` — сразу создать игру
- `-- --drop=10` — появиться на 10 м выше (проверка урона от падения)

## Файлы
- `main.gd` — меню, сеть (ENet, порт 7777), спавн игроков, счёт и килфид
- `player.gd` — движение, стрельба, урон/смерть/возрождение, синхронизация
- `map.gd` — арена (башня, галереи, укрытия, точки появления)
- `hud.gd` — прицел, HP, патроны, таблица, пауза

Настройки оружия и падения — константы в начале `player.gd`:
урон (22 в тело / 60 в голову, падает до 60% на 25–70 м), 600 выстр/мин, магазин 30, перезарядка 1.9 с,
урон от падения: без урона до ~2.5 м, дальше 7 HP за каждый м/с скорости приземления
(3.5 м ≈ 13, вышка 6 м ≈ 35, 12 м ≈ 75).
- `sfx.gd` — звуки (генерируются кодом), `fx.gd` — вспышки, трассеры, гильзы, искры, дырки от пуль
